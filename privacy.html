Sofia · Privacy · Use

Privacy and data handling

This notice describes the owner's private Sofia installation. It is not the privacy policy of Nous Research, Google, OpenAI, Anthropic or Kimi.

Data accessed and purpose

With the owner's authorization, the application reads Calendar events and associated details, Gmail messages and thread metadata, and selected Drive file metadata and content. It uses these sources to answer the owner's requests, prepare drafts and preserve source-backed working context. Identity details are used to verify the connected account.

Storage and processing

OAuth credentials are stored on the owner's Mac in an encrypted local store protected by operating-system file permissions. The encryption key is also stored on that Mac. Retrieved files, drafts, selected memories and source metadata may remain in local private directories and owner-controlled backups until the owner removes them.

Deterministic parsing and local-model processing run on the owner's Macs. When the owner requests work using a configured cloud model, necessary excerpts may be processed by OpenAI, Anthropic or Kimi under the owner's account settings. Selected answers may be delivered to the owner's private Telegram chat. The app does not publish a mailbox or an entire Drive archive to these services. Local-only tasks use the separately restricted local processing path.

Use limits and control

The application does not sell Google data, use it for advertising, or operate a generalized model-training pipeline. Its use of Google API data follows the Google API Services User Data Policy, including Limited Use requirements.

The owner can revoke a connection in Google Account connections, stop the local services, and remove selected local records and backups. Revocation stops future authorized API access; it does not itself delete previously saved local files.

Support contact is the owner-controlled email displayed on the Google consent screen. This installation does not accept accounts from outside users.
