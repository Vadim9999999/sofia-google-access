Sofia · Privacy · Use

Sofia — personal workspace assistant

Sofia is a personally operated assistant installed on its owner's Mac. It reads selected calendar events, email threads and Drive documents to help the owner prepare briefs, find information and review commitments.

This installation serves one owner. It has no public registration, shared inbox or service offered to outside users.

Google access

The Google consent-screen application is currently named Hermes Air Calendar. These pages describe that same private Sofia installation and its separate read-only Google connections.

Calendar, Gmail and Drive use separate read-only connections. Calendar uses the owner's work account; Drive and Gmail use the owner's personal account. Each reader checks the intended account before retrieving data.

The application cannot send email, change calendar events, edit or share Drive files through these connections.
